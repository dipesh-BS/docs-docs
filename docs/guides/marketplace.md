# Marketplace and registry: deferred

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Marketplace expansion and automatic registry publication are outside the current release. A project should become usable without any registry listing.

Existing marketplace code may remain for compatibility. Listing is discovery metadata; it does not issue a token or prove endpoint health. Public publication must be an explicit later action and must never expose credentials or private docs.
