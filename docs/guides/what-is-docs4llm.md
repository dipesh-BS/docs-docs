# What is docs4llm?

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Docs4llm converts documentation into a hosted knowledge source. Agents use documentation tools to search sections, read saved pages and cite original URLs. Tinyfish supplies extracted content; docs4llm supplies storage, retrieval and the MCP interface.

The release focuses on reliable website crawling and connection. It does not require users to deploy a server, build a local index or design extraction schemas.
