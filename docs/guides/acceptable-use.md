# Acceptable use

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Only process documentation you are authorized to access and use. Respect source terms, crawl restrictions and access controls. Do not use the service to collect sensitive personal data, overload sources or access another user's project.

This is an operational scope summary, not a newly approved legal contract. Legal text must be reviewed by the owner before publication. Report abuse to docs4llm@gmail.com.
