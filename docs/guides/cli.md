# Existing CLI

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

The CLI is an optional client of the hosted service. The release prioritizes the web journey, and credential changes require CLI regression checks.

Existing commands include docs4llm login, docs4llm <docs-url>, docs4llm list, docs4llm install <projectId>, docs4llm chat [target], whoami and logout. The current parser does not declare docs4llm add. No local server deployment is required, and no new CLI/package publication is part of documentation preparation.
