# Privacy scope

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

The service processes account identity, submitted URLs, extracted documentation, job metadata and access credentials. The target architecture sends source URLs/content to Tinyfish and selected retrieved content to OpenRouter for optional analysis or Q&A.

Do not submit confidential or sensitive data to the public-docs release. Do not claim fixed retention, training exclusions, data residency or compliance certifications without verified provider terms and an owner-approved policy. This page is a release scope summary awaiting legal review.
