# Create your first MCP

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Follow [Quickstart](quickstart.md). Choose a small public documentation site first. Review saved pages, warnings and a representative search before connecting your editor.

Use the endpoint and credential from the same project. Token replacement should be independent of crawling in the shipping flow. The current credential-delivery gap must be fixed before this experience is advertised as complete.
