# Self-hosting: outside release scope

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Self-hosted MCP export and standalone Node server deployment are outside the current release. Existing export code is legacy and is not a supported shipping path.

Use the [hosted service](deployment-hosted.md). Local development tooling remains available to contributors; it is not an end-user deployment product.
