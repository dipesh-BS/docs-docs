# Private documentation: deferred

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

This release focuses on publicly reachable documentation. Sites behind SSO/VPN or requiring authenticated crawling are not promised support.

Do not publish confidential content or expose a private mirror just to make a crawl succeed. Existing token protection controls access to saved docs; it does not grant permission to crawl the source. Authenticated-source integration requires a separate design.
