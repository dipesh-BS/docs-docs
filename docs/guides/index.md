# Documentation

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Docs4llm makes documentation searchable by AI agents through a hosted MCP endpoint. Tinyfish crawling and the simplified connection journey are the current shipping direction.

Start with [Quickstart](quickstart.md), [How it works](how-it-works.md), [Crawling](crawling.md), [Search](retrieval.md) and [Connect an editor](mcp-setup.md).

The migration is in progress. A written specification is not proof of a deployed feature. No universal conversion-time guarantee or standalone server deployment is included.
