# Quickstart

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Target journey:

1. Paste a publicly reachable documentation URL and select Create MCP.
2. Sign in if prompted; your URL is preserved and resumes once.
3. Watch saved progress while Tinyfish gathers pages and docs4llm indexes them.
4. Inspect extracted pages and any failures.
5. Issue a project connection token and select your editor configuration.
6. Ask the assistant to search your connected documentation.

Credential issuance and Tinyfish integration are shipping work. Use the deployed UI's verified capabilities until those changes are released. If the displayed token is a placeholder, do not paste it into an editor; report the credential-delivery issue.
