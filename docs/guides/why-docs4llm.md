# Why docs4llm?

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Pasting a short page can be enough for a one-off question. A connected documentation source becomes useful when an agent repeatedly needs different parts of a larger site: it searches first and reads only relevant sections.

A URL alone depends on the assistant's browsing tools. MCP provides a reusable tool interface to an extracted corpus. Quality still depends on extraction, coverage and retrieval; answers can be wrong, and saved pages remain snapshots until refreshed.
