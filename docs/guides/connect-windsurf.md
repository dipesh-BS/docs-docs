# Connect Windsurf

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Use the current Windsurf client's remote MCP configuration with the hosted project URL and Authorization bearer header. Prefer a client-specific configuration generated and tested by docs4llm; do not assume the Cursor JSON shape works unchanged in every client version.

Keep the token private. Reload the connection, check available documentation tools and run a source-verifiable search. A placeholder token or mismatched domain is a connection error, not a reason to recrawl.
