# Convert documentation

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Submit the documentation URL rather than a marketing home page. Optional focus instructions can prioritize topics such as authentication or webhooks; a URL alone must work.

The backend enforces a crawl scope and budget. Read partial-result warnings before relying on the corpus. Large or interactive sites may take longer. Retry failed pages when supported rather than assuming the entire site was captured.
