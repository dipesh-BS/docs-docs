# Connect an editor or agent

> Updated 2026-10-20. Target release documentation; verify deployed capabilities before relying on planned features.

Select a ready project, issue a project connection token and choose the client-specific configuration. Verify the endpoint's domain and project ID before installing it. Never copy a redacted placeholder.

Use [Cursor](connect-cursor.md), [VS Code](connect-vscode.md), [Claude](connect-claude.md), [Windsurf](connect-windsurf.md), or [agent frameworks](connect-openai.md).

A browser OAuth registration prompt is a separate flow. Fixed-token setup must send the Authorization header. Website login does not implement MCP OAuth.
